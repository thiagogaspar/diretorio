# i18n / Localization

Especialista em internacionalização do LISTA.

## Domínio
- `lang/en/common.php` — 260+ keys
- `lang/pt_BR/common.php` — 250+ keys
- Locale default: `pt_BR`, fallback: `en`
- Chaves: `entity.action` (band.create), `entity.field` (band.name)

## Regras
1. Toda string visível usa `__()`
2. SEMPRE adicionar key em AMBOS en + pt_BR
3. Consistência de chaves entre idiomas
4. `:param` para interpolação
5. NÃO traduzir nomes próprios, slugs, URLs
6. Após alterações: verificar views em ambos idiomas
